# JavaScript Basics — Week 1

## About this task
This project contains ten beginner-level JavaScript exercises covering arrays, objects, functions, strings, and DOM manipulation.

## Files
- `exercises.js` — Exercises 1–9
- `index.html` — Exercise 10: DOM manipulation
- `learning-note.md` — Summary of what I learned

## How to run
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `node exercises.js`.
4. Open `index.html` in a browser to test the DOM exercise.

## Concepts practised
Arrays, loops, functions, objects, string methods, and DOM event listeners.
