# Week 1: JavaScript Basics — Learning Note

In this task, I practised JavaScript concepts through ten exercises.

- **Arrays:** I learnt to calculate the sum of an array, find the largest number, filter even numbers, and remove duplicate values.
- **Strings:** I practised counting words and capitalizing words in a sentence.
- **Objects:** I created a student object, accessed its properties, and used `Object.values()` to retrieve values.
- **Functions and loops:** I wrote reusable functions and used loops to solve problems such as calculating a factorial.
- **DOM manipulation:** I used `getElementById()` to select HTML elements and `addEventListener()` to respond to a button click.
- **Testing:** I used `console.log()` to check outputs and tested the DOM exercise in a browser.

This task helped me understand how JavaScript works with data and how it can make a webpage interactive.
