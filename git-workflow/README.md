
# Hello World - Git Workflow

## Objective
This project demonstrates a basic Node.js program and Git workflow.

## Requirements
- Node.js
- Visual Studio Code
- Git

## How to Run
Open the terminal in the project root and execute:

```bash
node git-workflow/hello.js
```

## Expected Output
```text
Hello, World!
```
## Git Workflow Practised

- git init
- git status
- git add
- git commit
- git log
- git push
